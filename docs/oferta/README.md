# Funil de Oferta — Lente Clínica

Estratégia de aquisição de volume (SaaS front-end) + monetização em esteira (supervisão high-ticket).

## Contexto

- **Produto de entrada:** Acesso anual à plataforma Lente Clínica
- **Produto principal:** Curso de Supervisão Médica para Terapeutas (casos reais da Dra. Tatiana)
- **Audiência:** Psicólogos sem formação em psicofarmacologia
- **Fonte dos casos clínicos:** Consultório da Dra. Tatiana (anônimos)
- **Ponto de partida:** Audiência zero — 100% tráfego pago

## Economia do Funil

| Evento | Valor |

| SaaS anual | R$ 97–147 |
| Bump 1 — Acesso Vitalício | +R$ 47 |
| Bump 2 — Manuais PDF | +R$ 29,90 |
| **Receita máxima no dia 1** | **até R$ 224** |
| Curso high-ticket | R$ 997 |

Meta: CAC < R$ 174 → curso é lucro puro.

## Princípios

1. Tráfego frio exige autoridade rápida — anúncio ataca dor, não vende produto.
2. Order bumps recuperam CAC antes do high-ticket.
3. Webinário transforma casos do consultório em produto — sem criar conteúdo novo.
4. Follow-up segmentado por comportamento, não mensagem genérica.
